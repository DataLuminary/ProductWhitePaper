# AI 洞察

> **受众**：产品经理、业务用户、售前、交付  
> **开发说明**：[AI 洞察 · 设计与实现](../develop/ai-insights.md)

DataLuminary 用 **一个** AI 对话框完成问数、洞察和生成图表 / 仪表盘。逻辑名 **DataInsight**。这是 **Pro** 能力；Free 用户仍能看见入口，点击后引导升级，传统拖拽 BI 路径不变。

## 用户能做什么

| 能力 | 说明 |
|------|------|
| 自然语言问数 | 例如「近 30 天销售额趋势」——围绕空间内你有权限的数据集回答 |
| 可解释洞察 | 趋势、环比、同比、TopN、贡献度、简易异常；**数字来自平台查询**，不是模型口算 |
| 一句话生成 | 生成可继续编辑的图表与仪表盘，并跳进现有编辑器 |
| 自配模型 | 在空间设置里配置 DeepSeek、豆包（火山方舟）、OpenAI、Anthropic、Gemini 或 OpenAI 兼容接口；密钥只写不读 |

## 怎么用

1. 登录后进入某个空间。
2. 右下角蓝色 AI 按钮（DataInsight）。
3. 没有 Pro / `ai.analysis` 权益时：点击弹出升级提示。
4. 有权益时：打开对话面板；可直接问数，或说「生成一张折线图 / 销售仪表盘」。
5. 管理员在 **空间设置 → AI 洞察 / 模型配置** 填写提供商与密钥。未配置模型时，仍可按数据集字段做基础问数与配图。

分享页、嵌入页、纯渲染页 **不会** 打开 AI。

## 权限与商业

```text
登录（Logto）→ 会员权益 ai.analysis → 空间 / 数据集 / 仪表盘权限（Casbin）
```

- **没付钱**：入口可见，点击升级。
- **没资源权限**：对话里提示申请访问，而不是一串技术错误。
- 图表永远绑定 **数据集**，不能让 AI 直连业务数据库。

## 不会做的事

- 不会让模型写原始 SQL 或 HTML。
- 不会自动删除仪表盘或图表。
- 不会在对话里回显完整模型密钥。
- 不会把 Free 版的传统 BI 改成「必须用 AI」。

## 与生态的关系

模型调用走 LuminaryWorks AI Platform 契约（本地 BYOK 适配器可先落地；设中央网关地址后可切换）。领域智能（语义层、分析引擎、ChartIntent）留在 DataTalk，不交给中央网关判权限。

生态说明见 [启明工坊 · AI 平台](https://docs.luminaryworks.dev/develop/ai-platform)（上线后）及 MetaRepo 规格。
