# 场景化 Demo 展厅

DataLuminary 用 **场景模板** 展示完整分析链路：行业问题 → 确定性数据包 → 大屏与分析看板 → 只读预览 → 浏览器内试编辑 → 登录后应用到个人空间。公共 Demo **不会**持久化访客草稿，也不会把 Demo 数据源凭据复制到客户空间。

## 体验路径

1. **只读预览**：在场景展厅打开模板，查看 KPI、数据来源与 1920×1080 大屏。
2. **试编辑**：可拖拽、改配置，改动只留在当前浏览器标签；保存 / 发布 / 删除不可用，刷新后恢复模板。
3. **应用模板**：登录后把布局与查询语义复制到自己的空间，并映射自己的数据集。Demo 库账号不会随模板带走。

## 首批行业

每个行业提供 **2 套自由布局大屏** 与 **1 套网格分析看板**。经营明细默认是仓内可重复生成的合成数据；市场分析的宏观指标来自离线冻结的世界银行公开数据（CC BY 4.0）。

| 场景 | 回答的问题 | 核心 KPI | 数据说明 |
|------|------------|----------|----------|
| 企业财务 | 收入利润是否达标，关账与现金是否受控 | 收入、利润、预算偏差、现金余额 | 合成复式记账，借贷平衡 |
| 会计审计 | 哪些凭证和付款异常需要调查 | 发现项、借贷不平、重复付款、Benford 偏离 | 合成凭证 / 发票 / 付款，含可验证异常 |
| 供应链 | 交付是否准时，库存与供应商风险在哪 | OTIF、缺货、库存、高风险供应商 | 合成采购 / 收货 / 发运 / 缺货 |
| 游戏运营 | 活跃、付费与区服是否健康 | DAU、收入、D7 留存、区服告警 | 合成匿名玩家，不含真实账号 |
| 电商营销 | 增长是否来自健康渠道与活动 | GMV、净收入、ROAS、退款率 | 合成匿名订单；未混入公开零售明细 |
| 市场分析 | 份额、获客成本与区域机会 | TAM、份额、获客成本、机会分 | 世界银行宏观 + 合成投放与份额 |

## 使用注意

- 展厅需要登录（含公开 Demo 只读账号）。访客不能改公共数据。登录与产品共用同一套统一账号。
- 地图使用产品内已有世界地图，不引入第三方 GeoJSON。
- 把模板用到自己的数据时，必须完成数据集映射；未映射的查询面板会保持未绑定。

工程规格见平台仓库 `spec/features/scenario-demo.md`。图表与布局能力见 [仪表盘与布局插件](./dashboard-layout-plugins.md)。
