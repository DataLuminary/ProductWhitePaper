# 富文本图表插件

富文本是 DataLuminary 中的 **文本类可视化组件**：与折线、指标卡一样绑定数据集与查询，用叙述性 Markdown 把指标写进业务说明里。

## 适用场景

- 看板标题旁的经营解读、周报摘要
- 在段落中嵌入「本周销售额」「某分类浏览量」等动态数字
- AI 生成洞察文案后，由业务人员可视化微调措辞与指标筛选

## 使用方式

1. 在图表类型中选择 **富文本**。
2. 与普通图表一样配置数据集、维度与度量。
3. **打开图表编辑器**，在中间预览区用 Segmented 切换：
   - **编辑**：大画布撰写 Markdown，工具栏「插入指标」嵌入数据胶囊（画布上不可直接编辑）
   - **预览**：查看绑定数据后的最终效果
4. 右侧配置面板设置 **Markdown 主题**（默认 / GitHub / Notion）与 **指标语义色**（success / warning / danger / neutral）；样式只作用于当前富文本图表。

## 编辑 / 查看

| 场景 | 行为 |
|------|------|
| 图表编辑器 · 预览区「编辑」 | 可编辑正文（唯一编辑入口） |
| 图表编辑器 · 预览区「预览」 | 只读渲染 |
| 图表编辑器 · 配置面板 | 主题与语义色 |
| 仪表盘画布 / 分享查看 | 只读渲染 |

## 能力要点

| 能力 | 说明 |
|------|------|
| 半依赖查询 | 正文先展示；查询返回后刷新指标，不整块空白等待 |
| 行筛选 | 可按维度值匹配某一行（如 `weekviews = 1`） |
| 前端聚合 | 多行命中时可 sum / avg / max / min |
| 阈值着色 | 可选阈值，高于 / 低于时切换胶囊语义色 |

## 底层约定（给集成方）

- 持久化字段：`panel.config.content`（MDX 字符串）
- 动态节点：`<BIMetric metric="..." match={{ ... }} />`
- 工程说明见 DataView `spec/development/rich-text-panel.md`
