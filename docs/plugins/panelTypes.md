## 图表类型说明

内置面板 `kind`（与 DataView `src/plugins/panels/*/package.json` 对齐）：

| kind | 说明 |
|------|------|
| `table` | 表格 |
| `line` / `area` / `area-stack` | 折线 / 面积 |
| `bar` / `bar-stack` / `bar-horizontal` / `bar-horizontal-stack` | 柱状 / 条形 |
| `bar-line` | 柱线组合 |
| `pie` / `ring` / `rose` | 饼图系列 |
| `scatter` | 散点图 |
| `funnel` | 漏斗图 |
| `gauge` / `liquid` / `radial` | 仪表 / 水球 / 径向 |
| `number-panel` | 数字指标卡 |
| `word-cloud` | 词云 |
| `map` | 地图 |
| `rich-text` | [富文本](./rich-text.md)（Markdown + 动态指标胶囊） |
| `image` / `video` | 图片 / 视频（媒体，不依赖查询） |
