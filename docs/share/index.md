# 分享：对外分发仪表盘

DataLuminary 的「分享」指把空间内的仪表盘**分发到平台编辑器之外**，当前落地为两条互补能力：

| 能力 | 方向 | 用户感知 | 文档 |
|------|------|----------|------|
| **嵌入分享** | 拉：宿主系统挂载仪表盘页 | 业务系统内嵌看板，实时查询 | [仪表盘嵌入分享](./embed.md) |
| **订阅推送** | 推：按周期把快照发到邮箱 | 邮件收到截图 / 可选 PDF | [订阅推送](./subscription.md) |

二者都服务「让正确的人在正确的场景看到仪表盘」，但交互模型不同：嵌入是**在线只读会话**；订阅是**离线快照投递**。

---

## 产品入口

| 能力 | 入口 |
|------|------|
| 嵌入分享 | **空间 → 分享 → 仪表盘嵌入管理** |
| 订阅推送 | **空间 → 订阅推送**（列表 / 新建编辑 / 推送记录）；仪表盘详情页邮件图标可预填仪表盘新建订阅 |

---

## 如何选型

| 场景 | 更合适 |
|------|--------|
| 把看板嵌进 CRM / OA / 门户，需要实时数据与交互 | **嵌入分享** |
| 定时给老板 / 运营发「这一版画面」，不要求登录产品 | **订阅推送** |
| 客户系统强隔离、零改造接入 | 嵌入：iframe / CDN SDK |
| 收件人只有邮箱、无 SSO | 订阅：邮件 tags 收件人 |

---

## 能力状态（摘要）

| 项 | 嵌入分享 | 订阅推送 |
|----|----------|----------|
| v1 交付 | iframe / JS SDK / Micro App / Wujie；启停与公开令牌 | 邮件渠道；列表 / 编辑 / 启停 / 测试 / 推送记录 / 重发 |
| 鉴权 | 公开 token → 短期 `share-view` JWT | 管理端 JWT；无头渲染用短期 render JWT |
| 未开放 | 图表级嵌入、访问日志、npm SPA 组件 | 企微推送、仪表盘变量参数块 |
